## 📌 Features

- Predicts best crop based on soil nutrients
- Modern interactive UI
- AI-powered recommendations
- Real-time prediction
- Streamlit web application

---

## 🧠 Machine Learning Model

- Random Forest Classifier

- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)

- Humidity
- pH Value
- Rainfall
